# Lenguajes de Programación - Trabajos Prácticos

**Alumno:** Facundo Cichero  
**Profesor:** Pablo Pandolfo  
**Materia:** Lenguajes de Programación  

Este repositorio contiene la entrega de los Trabajos Prácticos (1 al 5) de la materia.

## Estructura del Repositorio

- **[TP1 - Clasificación de los LP](./TP1_Clasificacion):** Clasificación detallada de 5 lenguajes modernos (ReScript, Unison, Hylo, Inko, Gren) según taxonomías específicas y datos de color.
- **[TP2 - Análisis de Datos](./TP2_AnalisisDatos):** Limpieza y visualización de datos referidos a lenguajes de programación utilizando un entorno de Notebooks.
- **[TP3 - Multiparadigma](./TP3_Paradigmas):** Solución a un problema de búsqueda utilizando diferentes paradigmas (Imperativo, Orientado a Objetos, Funcional, Lógico) y tabla comparativa.
- **[TP4 - Gramática de Sentencias](./TP4_GramaticaIF):** Identificación de la gramática del `if` en distintos lenguajes, reescribiendo producciones desde el axioma hasta los terminales.
- **[TP5 - Lenguaje BRA](./TP5_GramaticaBRA):** Comparativa de formatos BNF, EBNF y ABNF para el lenguaje BRA (Tabla 61C).
